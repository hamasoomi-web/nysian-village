# My Journal — بولت ژورنال دیجیتال

نسخه اولیه قابل اجرا از یک ژورنال شخصی فارسی با Flask و SQLite.

## امکانات موجود
- ثبت‌نام با نام، نام خانوادگی، نام ژورنال، ایمیل و رمز عبور
- ورود و خروج امن با هش رمز عبور
- داشبورد شخصی
- وظایف: ایجاد، جست‌وجو، فیلتر، تکمیل، حذف و تعیین زمان یادآوری
- تقویم ماهانه با پشتیبانی از نمایش ماه و روز شمسی (در صورت نصب jdatetime) و ثبت رویدادهای زمان‌دار
- اعلان مرورگر برای یادآوری وظایف و رویدادها؛ مرورگر باید باز باشد و اجازه اعلان داده شده باشد
- دفتر روزانه با حال روز، قدردانی، موفقیت‌های روز و بازتاب شخصی
- گزارش خلاصه وظایف، اهداف، عادت‌ها و نوشته‌های روزانه
- یادداشت‌ها: ایجاد، ویرایش، سنجاق‌کردن و حذف
- اهداف با درصد پیشرفت
- پیگیری عادت‌های روزانه
- ساخت و ویرایش صفحات شخصی با عنوان، آیکون، رنگ و متن
- ساخت قالب‌های شخصی قابل استفاده مجدد برای صفحه‌ها
- جابه‌جایی کارت‌های داشبورد با Drag & Drop و ذخیره چیدمان
- جست‌وجوی یکپارچه در وظایف، یادداشت‌ها، اهداف و صفحه‌ها
- تنظیم تم روشن، تاریک، کاغذی، سبز و بنفش
- تغییر رنگ اصلی، اندازه فونت، نام و نام خانوادگی و نام ژورنال
- خروجی پشتیبان JSON و واردکردن داده‌ها از فایل پشتیبان
- محافظت CSRF בסיסی و جداسازی داده‌ها بر اساس کاربر
- رابط فارسی راست‌چین واکنش‌گرا

## نصب در ویندوز

1. Python 3.10 یا جدیدتر نصب باشد.
2. این پوشه را باز کن و ترمینال را در همان مسیر اجرا کن.
3. محیط مجازی بساز:

```powershell
py -m venv .venv
.venv\Scripts\activate
```

4. وابستگی‌ها را نصب کن:

```powershell
python -m pip install -r requirements.txt
```

5. یک کلید محرمانه تصادفی در متغیر محیطی `SECRET_KEY` تنظیم کن. برای تست محلی می‌توانی بدون آن اجرا کنی، اما برای میزبانی اینترنتی حتماً کلید قوی تنظیم کن.

```powershell
$env:SECRET_KEY="put-a-long-random-secret-here"
python app.py
```

6. در مرورگر به `http://127.0.0.1:5000` برو و حساب بساز.

## اجرا در Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
export SECRET_KEY="put-a-long-random-secret-here"
python app.py
```

## پایگاه داده
فایل SQLite در `instance/journal.db` ساخته می‌شود. برای پشتیبان‌گیری کامل، برنامه را متوقف و از این فایل یک کپی تهیه کن؛ همچنین از داخل سایت می‌توانی داده‌های اصلی را به JSON خروجی بگیری.

## نکات استقرار
- `FLASK_DEBUG` را در محیط عملیاتی فعال نکن.
- `SECRET_KEY` قوی و محرمانه تعیین کن.
- از سرور WSGI مانند Gunicorn استفاده کن.
- برای استفاده چندکاربره واقعی، HTTPS، سیاست پشتیبان‌گیری و مدیریت مهاجرت پایگاه داده را تنظیم کن.
- اعلان‌ها در این نسخه با باز بودن سایت و اجازه اعلان مرورگر کار می‌کنند؛ اعلان سمت سرور در زمان بسته بودن مرورگر یا نصب PWA هنوز پیاده‌سازی نشده است.
- جابه‌جایی Drag & Drop فعلاً برای کارت‌های داشبورد است؛ ویرایشگر آزاد بلوکی برای چیدن هر نوع جزء دلخواه داخل هر صفحه، و تنظیم منطقه زمانی، هنوز به توسعه بیشتر نیاز دارند.
- اگر از نسخه قبلی پایگاه داده‌ای دارید، چون مدل‌ها گسترش یافته‌اند، برای شروع کاملاً تمیز در محیط آزمایشی می‌توانید فایل `instance/journal.db` را پس از تهیه پشتیبان حذف کنید تا جداول جدید ساخته شوند. در محیط واقعی از مهاجرت پایگاه داده استفاده کنید و داده‌ها را بی‌پشتیبان حذف نکنید.
- در محیط فعلی ساخت فایل، وابستگی‌های Flask نصب نبودند و دسترسی اینترنت برای نصب آن‌ها فراهم نشد؛ بنابراین کد Python و قالب‌های Jinja از نظر نحوی بررسی شده‌اند، اما اجرای کامل و آزمون end-to-end هنوز تأیید نشده است.
